# 公众号宣传文案 — 中银（天津）律所获客内容

## 概述

Arron 为中银（天津）律所制作微信公众号宣传文案及配套卡片图，目的是获客——让读者读完产生疑惑、主动咨询，而非读一篇案例总结。2026-08-13 首单，用户最终确认模板并明确"以后就做成这样的就行"。

## 文案写法（用户确认的最终模板）

**核心定位**：获客宣传，不是法律分析。提出真问题但不给答案，留悬念勾咨询需求。

- **白话，老板口吻** — 不用法言法语、案号、"法院认为"、一审二审判决。老板怎么说话就怎么写。
- **问题导向** — 每个"情形"描述"发生了什么/遇到了什么问题"，开放式提问，不下结论。
- **留悬念但不直白挑逗** — 不给答案让读者犯嘀咕，但避免"打问号""睡不着觉"这类直白挑逗词。
- **短篇幅** — 300 字左右。
- **结构固定**：问句标题 → 开头（常见误判 +"这个问题的答案，可能和很多人想的不太一样"）→ 情形一/二/三 → 结尾（风险提示 + 咨询引导）→ 💡中银律师温馨提示（简化为风险提示，不写服务菜单）。
- **标题要全面覆盖** — 问句标题要能盖住所有情形，不能只聚焦其中一个（如"签了终止协议就不是股东"只盖住情形一，被要求改成"小股东想查账公司总有理由拒绝"这类概括式）。
- **情形抓法律实质，不抠表面字眼** — 描述争议点时落到规则本质，不纠结表述用词。例："拍摄"不是重点，实质是"查阅≠复制，股东无复制权"。
- **角色定位基于案卷事实** — 写"小股东""大股东"等定位前先核对持股比例/案卷事实，不能想当然。

### 最终版示例（知情权案例，2026-08-13）

> 标题：出了钱，想查账，怎么就这么难？
>
> 开头：投了钱当了股东，想看财务报表和会议记录——这是再正当不过的权利。可如果投的不是公司，而是一家民办学校、培训机构、研究院，对方一句"我们不是公司，公司法管不着"，就可能让你吃闭门羹……这个问题的答案，可能和很多人想的不太一样。
>
> 情形一：出资方觉得，钱是我出的，看账本天经地义。可对方搬出登记证书——民办非企业单位，不适用公司法。法律没写举办者有知情权，你凭什么查？……到底是不是一项受法律保护的权利？
>
> 情形二：章程里写了出资方有权"参与管理"，出资方认为查账、看报告是参与管理的基础。对方却咬死四个字——章程说的是"参与管理"，没说"查阅复制"，你无权看。几个字的差别，能不能推导出知情权，不是那么容易说清楚的事。
>
> 情形三：就算能查，能查到什么程度？财务报表也许可以，但原始凭证呢？银行流水呢？合同和付款记录呢？知情权的边界画在哪里，法律没有一一列明，实践中的分歧也不小。
>
> 结尾：出资人的知情权，不因为投的是一家"非公司"就自动消失。但怎么主张、依据什么、能查到哪一步——这些问题，签协议之前搞清楚，比出了纠纷再想办法划算得多。

## 卡片图生成（技术方案）

微信公号卡片图标准尺寸 **1080×1350**。本机生成中文图的可复用方案：

- **限制**：无 Python；node-canvas 需 gyp 编译（无 Python 装不上）；Jimp 不能渲染中文字体。
- **方案**：写内联 CSS 的 HTML（body 固定 1080×1350）→ Chrome headless 截图：
  `"/c/Program Files/Google/Chrome/Application/chrome.exe" --headless --disable-gpu --screenshot="out.png" --window-size=1080,1350 --force-device-scale-factor=1 "file:///...html"`
- **参考图分析**：用 Jimp 像素采样定配色/布局（getPixelColor 逐点扫描），tesseract.js `chi_sim` OCR 提取参考图文字。
- 产物：`workspace/card_v1.png`（橙蓝）、`workspace/card_v2.png`（蓝金），HTML 模板 `workspace/card_image*.html`。
