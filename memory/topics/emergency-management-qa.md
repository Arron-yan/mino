## 搜索工具功能

- **搜索模式**：关键词实时搜索，匹配标题/咨询/答复/注释，高亮显示，按相关度排序
- **全文浏览模式**：按 11 章折叠展开，逐条 Q&A 展开阅读，内置筛选搜索
- **章节筛选**：搜索模式下可按章节过滤
- **地方规定标记**：114 条涉"当地规定"的答复自动标 🌐 标签
- **各地应急管理厅官网**：33 个省/自治区/直辖市应急管理厅（局）直达链接
- **政府网站搜索**：面板内输入关键词，调用 Bing `site:gov.cn` 搜索各地应急管理局网站
- **专家注释**：10 条绿底注释补充官方答复中缺失的法律依据和解释

## TOC 修正

- 原文档目录标题与正文标题存在 114-151 处不一致：措辞修改、标点规范、条目移位等
- 写了一个 Node.js 脚本（`workspace/fix_toc.js`）自动比对正文标题并更新目录
- 关键技术：从后往前处理避免 XML 位置偏移；PowerShell Compress-Archive 打包 docx；中文引号规范化（U+201C/U+201D 替换 ASCII U+0022）
- 此脚本可复用于后续文档版本更新

## 技术踩坑

- **环境限制**：无 Python、无 pandoc、无 zip CLI。可用：Node.js、unzip、PowerShell Compress-Archive
- **docx 操作**：docx = zip 文件，unzip 解压 → 编辑 word/document.xml → PowerShell 打包为 .zip → 重命名为 .docx
- **模板字面量**：JS 模板字面量中嵌套正则和反斜杠的转义极复杂，改用独立文件 + fs.readFileSync 拼接
- **XML 批量替换**：从后往前处理避免索引偏移（sort descending by position）
- **shell 限制**：Git Bash 的 `mkdir -p` 和 `zip` 不可用；execSync 使用 cmd.exe；优先用 Node.js fs 操作替代 shell 命令
