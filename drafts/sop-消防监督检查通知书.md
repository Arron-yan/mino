# 消防监督检查通知书 SOP

> 适用文书：消防监督检查通知书 / 责令限期改正通知书 / 复查意见书等

---

## 一、收件检查

| 检查项 | 要点 |
|--------|------|
| 送达主体 | 单位名称全称是否准确、与营业执照一致 |
| 文书文号 | 年度+机关简称+文书类别+序号，格式是否规范 |
| 落款盖章 | 是否有消防救援机构公章（非科室章） |
| 送达回执 | 签收人、签收日期、送达方式是否填写 |

---

## 二、事实与依据

| 检查项 | 要点 |
|--------|------|
| 检查时间地点 | 日期、场所名称、具体位置是否明确 |
| 隐患事实描述 | 是否具体到部位/设备/行为，能否据以整改 |
| 引用规范条款 | 引用的法规名称、条、款、项是否准确、是否现行有效 |
| 隐患照片/附件 | 记载的照片编号与附件实物是否一致 |

---

## 三、整改要求

| 检查项 | 要点 |
|--------|------|
| 整改措施 | 是否明确、可执行（非笼统的"整改""完善"） |
| 整改期限 | 起算日、截止日是否合理，是否含节假日影响 |
| 复查安排 | 是否注明复查方式（书面/现场）、联系人及电话 |

---

## 四、救济与权利告知

| 检查项 | 要点 |
|--------|------|
| 陈述申辩权 | 是否告知提出异议的期限和受理机关 |
| 复议/诉讼途径 | 复议机关名称、复议期限（60日）、诉讼法院及时限（6个月）是否准确 |
| 联系人信息 | 承办人姓名、电话是否完整 |

---

## 五、常见格式瑕疵

- [ ] 单位名称与营业执照差一字（有限公司 / 有限责任公司）
- [ ] 文书日期早于检查日期
- [ ] 引用标准已废止（如 GB 50016-2006 → 应为 GB 50016-2014）
- [ ] 逾期不改的处罚依据未注明
- [ ] 印章模糊或无印章
- [ ] 送达回执与正本日期不一致
