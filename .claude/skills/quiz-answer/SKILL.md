# quiz-answer — 创业研究知识赛查答案

## 背景

Arron 参加创业研究专题赛道知识赛，题库共 225 题（单选 30×3、多选 15×3、判断 20×3、案例 10×3），
答案已录入 `question-bank.json`。本技能让他在答题时**发图/发文字即得答案**，桌面端与微信两个入口通用。

**识别不依赖"图片理解"视觉模型配置**——本地 OCR（tesseract.js + 中文语言包）即可离线识别截图，开箱即用。

## 资产（都在本技能目录）

| 文件 | 作用 |
|------|------|
| `question-bank.json` | 225 条题库（set/type/section/question/options/answer/caseTitle/caseDesc） |
| `answer-matcher.js` | 文字匹配引擎：`node answer-matcher.js "<题目文本>"`，支持 `--json`、多行 stdin |
| `ocr-answer.js` | 图片识别：`node ocr-answer.js "<图片路径>"`，OCR 后自动匹配并出答案 |

依赖：根目录 `node_modules` 的 `tesseract.js`、`jimp`；根目录 `chi_sim.traineddata`（首次运行自动 gzip 缓存到 `lang/`）。

## 标准流程

### 1. 定位图片

- **桌面端**：用户贴的图会以 `@myagents_files/xxx.png` 或工作区路径出现，直接用该路径。
- **微信**：收到的图片会落盘到工作区（多在 `myagents_files/` 或会话媒体目录），先 `ls` 找到实际路径。
- 用户只给图片、没打字 → 直接进入识别。

### 2. 识别并匹配

**图片优先（本地 OCR）**：

```bash
node "<技能目录>/ocr-answer.js" "<图片路径>"
```

- 内部会自动 2 倍放大提升小字识别率（可加 `--no-scale` 关闭）。
- 输出每道命中题的【答案】+ 匹配到的原题 + 置信度；未命中的块会列出供参考。
- 一张截图含多道题也能一次识别（按题号/空括号切分题目块）。

**文字（用户直接贴题目）**：

```bash
node "<技能目录>/answer-matcher.js" "<题目文本>"
```

### 3. 汇报

- **命中**：给用户 答案 + 匹配到的原题（方便他确认匹配对了），如 `答案：C（人本创业的核心要义是…）`。
- **多选/判断**：直接给 `ABC` / `×`/`√`。
- **未命中**：明确说"题库里没有这道题"，列出最接近候选；**不要硬编答案**。
- **置信度偏低**（0.55~0.75 且用户没把握）：提示"匹配可能不精确，建议核对原题"。

## 多题截图

一张图含多题时，`ocr-answer.js` 会逐题输出。汇报用紧凑格式：

```
1. C —— 人本创业的核心要义是…
2. B —— 最早将"企业家"一词引入经济学…
```

## 可选：视觉模型识别（更准）

本地 OCR 偶尔会认错个别字（如"熊"→"能"）。若用户在聊天工具栏开启了**图片理解**，可用视觉模型读题、准确率更高：

```bash
myagents vision analyze --image "<图片路径>" \
  --prompt "逐字提取图中每一道题的题干和 A/B/C/D 选项，每题单独输出一行。不要包含题号序号。"
```

再逐行喂给 `answer-matcher.js`。视觉工具未开启时保持本地 OCR 路径即可，不必强求。

## 边界与提示

- 题库外的题（正式比赛可能出变体/新题）→ 如实报未命中，不猜。
- 判断题答案显示为 ×/√。
- OCR 识别错字时，若 matcher 未命中但用户确认题干在题库中，可用视觉模型重读，或让用户粘贴文字。
- `ocr-answer.js` 首次运行会生成 `lang/chi_sim.traineddata.gz` 语言包缓存。
